# Обновление 3D Converter v1.0.24

Изменена только компоновка верхней строки панели настроек:

- Заголовок «Параметры конвертации» остаётся слева/в центральной части строки.
- Справа от него располагается поле «Масштабирование» с выпадающим списком.
- На широком окне список выровнен над колонкой «Аудиодорожки».
- На узком окне шапка адаптируется к двухколоночной раскладке.
- Остальные поля, команды FFmpeg, режимы GPU/CPU и обработка тестового интервала не изменялись.

Проверка: все существующие тесты проекта проходят.
