# 3D Converter v1.0.23 — обновление интерфейса и тестового фрагмента

## Масштабирование

Вместо вкладок используется обычный выпадающий список «Масштабирование» в общей панели параметров:

- **Авто (GPU)** — по умолчанию выбирает CUDA для NVIDIA или Intel VPP для QSV, если нужные фильтры FFmpeg доступны; иначе использует CPU Lanczos.
- **GPU** — принудительно требует подходящий аппаратный фильтр. Если фильтры отсутствуют, приложение показывает понятную ошибку и не начинает конвертацию.
- **CPU** — принудительно использует программный Lanczos, сохраняя аппаратное кодирование NVENC/QSV.

Выбор сохраняется между запусками. Для старого значения `software` из v1.0.22 автоматически выбирается `CPU`.

## Тестовый фрагмент

При включённом флажке поле поддерживает:

- `25` — первые 25 минут от начала;
- `10 - 125` — диапазон с 10-й по 125-ю минуту;
- `0:23:53 - 1:15:01` — диапазон по таймкодам (ЧЧ:ММ:СС; также поддерживается ММ:СС).

Пустое поле означает первые две минуты. Проверяется порядок границ и длительность исходного видео. FFmpeg получает `-ss` перед `-i` и `-t` с рассчитанной длительностью.

## Служебные окна

Вызовы FFprobe, FFmpeg для предпросмотра и анализа кадров, проверка аппаратных энкодеров, запрос списка фильтров и основной процесс конвертации используют `CREATE_NO_WINDOW` в Windows. Основное окно приложения и диалоги ошибок остаются видимыми.

## Установка

1. Сделайте резервную копию текущей папки проекта.
2. Распакуйте архив в папку проекта с заменой файлов.
3. Убедитесь, что `pubspec.yaml` содержит `version: 1.0.23`.
4. Выполните `python build.py`.

## Проверки

- `python -m py_compile *.py` — успешно.
- `python -m unittest discover -v` — 68 тестов пройдены.
- GUI и реальная конвертация в Windows должны быть проверены на целевом компьютере.
