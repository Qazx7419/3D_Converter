# 3D Converter v1.0.21 — аппаратное масштабирование Half TAB → Half SBS

## Что обновлено

### 3D Converter
- NVIDIA NVENC: Full SBS использует `scale_cuda`; Half TAB использует CUDA crop metadata, `scale_cuda` (Lanczos) для обеих половин и `overlay_cuda` для сборки Side-by-Side.
- Intel QSV: Full SBS использует `vpp_qsv`; Half TAB использует `vpp_qsv` для crop/scale обеих половин и `hstack_qsv` для сборки.
- Если в FFmpeg не хватает нужных фильтров, приложение сохраняет совместимый программный граф обработки с аппаратным кодированием.
- Аудио, субтитры, контейнеры, Auto Magic, пресеты, пауза/остановка, Drag & Drop и остальные настройки не менялись.

### Top_Half_SBS → Half_SBS BAT
- Добавлен отдельный BAT `Top_Half_SBS_to_Half_SBS_Gemini_Auto_2.9_CUDA.bat`.
- При наличии `scale_cuda` и `overlay_cuda` использует CUDA/NVDEC → CUDA crop/scale → overlay_cuda → NVENC.
- Если CUDA-фильтры отсутствуют, автоматически использует прежнюю программную обработку Lanczos с NVENC.
- Все прежние режимы качества, аудио, субтитров, контейнеров и тестового фрагмента сохранены.

## Установка проекта

1. Сделайте резервную копию текущей папки проекта.
2. Распакуйте архив поверх папки проекта с заменой файлов.
3. Убедитесь, что `pubspec.yaml` содержит `version: 1.0.21`.
4. Соберите EXE командой:

```bash
python build.py
```

## Использование BAT

Перетащите видеофайл на `Top_Half_SBS_to_Half_SBS_Gemini_Auto_2.9_CUDA.bat`. Далее выберите параметры в меню. Выходное имя по прежнему шаблону: `_HalfSBS`.

## Проверки

## Выбор режима масштабирования в v1.0.23

Выбор сделан обычным выпадающим списком в общей панели конвертации: «Авто (GPU)», «GPU» и «CPU». Автоматический режим использует CUDA для NVIDIA или Intel VPP для QSV, когда фильтры доступны; иначе переходит на программный Lanczos. Принудительный GPU-режим сообщает об отсутствующих фильтрах, а CPU-режим отключает аппаратное масштабирование, не отключая NVENC/QSV-кодирование. Выбор сохраняется между запусками.
