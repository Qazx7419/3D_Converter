# 3D Video Converter

**Windows-приложение для анализа, преобразования и перекодирования обычного и стереоскопического видео (3D).**

3D Video Converter — графическая программа на Python, предназначенная для работы с видеоформатами 2D, Side-by-Side (SBS) и Top-and-Bottom (TAB).

Приложение использует FFmpeg и FFprobe для анализа и обработки видео, поддерживает аппаратное кодирование NVIDIA NVENC и Intel Quick Sync Video (QSV), а также предоставляет инструменты управления качеством, битрейтом, аудиодорожками и выходными форматами.

## Основные возможности

### Анализ видео

- Автоматический анализ параметров видео через FFprobe.
- Определение разрешения, длительности, битрейта и видеокодека.
- Распознавание форматов Full SBS, Half SBS, Full TAB и Half TAB по доступным метаданным и обозначениям в названии файла.
- Предварительная оценка формата видео по соотношению сторон.
- Отображение рекомендаций по дальнейшей обработке.

Автоматическое определение учитывает, что одного разрешения недостаточно для достоверного распознавания всех стереоскопических форматов. В неоднозначных случаях предусмотрен ручной выбор операции.

### Поддерживаемые операции

| Исходный формат | Результат | Описание |
|---|---|---|
| 2D | MPEG-TS | Перепаковка без перекодирования видео и аудио |
| Full SBS | Half SBS | Уменьшение горизонтального разрешения стереопары |
| Half TAB | Half SBS | Разделение верхнего и нижнего изображений, масштабирование и объединение по горизонтали |

Для операций преобразования SBS/TAB предусмотрены варианты аппаратного кодирования через NVIDIA NVENC и Intel Quick Sync Video.

### Аппаратное ускорение

Программа проверяет доступность аппаратных кодировщиков и предлагает использовать поддерживаемое оборудование.

**Intel Quick Sync Video (QSV):**
- Аппаратное декодирование HEVC.
- Аппаратное масштабирование через Intel VPP.
- Аппаратное кодирование H.264.
- Поддержка гибридной обработки, когда геометрические фильтры выполняются на CPU, а кодирование — на GPU.

Для Full SBS → Half SBS реализована полностью аппаратная цепочка Intel QSV:

`HEVC QSV Decode → Intel VPP → H.264 QSV Encode`

**NVIDIA NVENC:**
- Аппаратное кодирование H.264.
- Использование NVDEC в предусмотренных профилях обработки.
- Настраиваемые пресеты и параметры качества.

**Программная обработка:**
- Возможность использовать CPU для операций, которые не поддерживаются выбранным аппаратным профилем.

### Настройки качества

Предусмотрены следующие режимы управления качеством и битрейтом:

- **Auto (Magic)** — автоматический подбор параметров в зависимости от характеристик исходника и кодировщика.
- **VBR Mbps** — задание среднего битрейта в мегабитах в секунду.
- **VBR MB/s** — задание битрейта в мегабайтах в секунду.
- **Target Size** — расчёт битрейта для достижения заданного размера файла.
- **CQ / ICQ** — управление качеством кодирования.
- **CBR Mbps** — режим постоянного битрейта.

Для Intel QSV и NVIDIA NVENC используются отдельные параметры качества и пресеты.

Дополнительно доступны настройки пресетов кодирования с автоматическим выбором рекомендуемого значения и возможностью ручного изменения.

### Контейнеры и аудио

Поддерживаемые выходные контейнеры:

- MP4
- MPEG-TS (TS)

Режимы обработки аудио:

- Перекодирование в AC3 с битрейтом 448 кбит/с.
- Копирование оригинальных аудиопотоков без перекодирования.

При использовании соответствующих профилей предусмотрена обработка субтитров с учётом особенностей выходного контейнера.

### Предпросмотр видео

- Выбор исходного видеофайла через диалог.
- Загрузка видео перетаскиванием файла из Проводника Windows на окно программы (Drag & Drop).
- В текущей версии за один раз загружается и анализируется один файл.
- Извлечение отдельного кадра в выбранной временной позиции.
- Перемещение по видео с помощью временного ползунка.
- Автоматическое масштабирование изображения под размер панели.
- Сохранение пропорций исходного изображения.

Предпросмотр позволяет визуально оценить исходный материал перед началом конвертации.

### Управление конвертацией

- Отображение прогресса выполнения.
- Отображение текущей скорости обработки относительно реального времени.
- Отображение времени конвертации.
- Вывод информации об используемом кодировщике и параметрах обработки.
- Поддержка тестовых фрагментов для проверки настроек перед обработкой полного видео.
- Проверка существования выходного файла.
- Возможность перезаписать существующий файл, выбрать собственное имя или отменить операцию.

### Интерфейс

- Графический интерфейс на CustomTkinter.
- Тёмная тема.
- Адаптивное расположение элементов.
- Автоматическое изменение размеров панелей и предпросмотра.
- Сохранение положения и размера окна между запусками.
- Отображение версии программы из `pubspec.yaml`.
- Контекстные подсказки для параметров качества с учётом выбранного кодировщика.

## Технологии

| Компонент | Назначение |
|---|---|
| Python | Основной язык разработки |
| CustomTkinter | Графический интерфейс |
| Pillow | Обработка и отображение изображений |
| tkinterdnd2 | Перетаскивание файлов в окно приложения |
| FFmpeg | Конвертация и обработка видео |
| FFprobe | Анализ видеофайлов |
| Intel oneVPL / QSV | Аппаратное декодирование и кодирование Intel |
| NVIDIA NVENC / NVDEC | Аппаратное кодирование и декодирование NVIDIA |
| PyInstaller | Создание Windows EXE |

## Требования

- Windows 10 / Windows 11.
- Python для запуска исходной версии.
- FFmpeg и FFprobe, добавленные в PATH.
- Совместимые драйверы видеокарты для использования аппаратного ускорения.
- Для Intel QSV или NVIDIA NVENC необходима поддержка соответствующего кодировщика драйвером и сборкой FFmpeg.

Набор Python-зависимостей находится в `requirements.txt`.

## Запуск из исходного кода

Клонируйте репозиторий:

```bash
git clone https://github.com/USERNAME/3D-Converter.git
```

Перейдите в папку проекта:

```bash
cd 3D-Converter
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустите программу:

```bash
python main.py
```

Для сборки Windows EXE используйте автоматический скрипт (он проверит и установит PyInstaller и необходимые зависимости):

```bash
python build.py
```

По умолчанию создаётся папка `dist/3D Converter/` с готовым приложением.

## Принципы разработки

При разработке используются проверенные сценарии FFmpeg, первоначально реализованные в BAT-файлах.

Алгоритмы обработки и кодирования вынесены в отдельный модуль `encoding_profiles.py`. Это позволяет независимо развивать графический интерфейс и алгоритмы обработки видео.

Особое внимание уделяется:

- Сохранению качества изображения.
- Корректной геометрии стереопары.
- Максимальному использованию аппаратных возможностей GPU.
- Сохранению аудиодорожек.
- Контролю выходных параметров.
- Совместимости с различными аппаратными кодировщиками.

## Статус проекта

Проект находится в активной разработке.

Реализованы базовые операции преобразования 2D/3D-видео, аппаратные профили Intel QSV и NVIDIA NVENC, управление качеством и адаптивный графический интерфейс.

Дальнейшее развитие предусматривает оптимизацию аппаратной обработки, расширение поддержки форматов и кодировщиков, совершенствование автоматического определения стереоформатов и развитие системы управления конвертацией.
