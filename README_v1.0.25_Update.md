# 3D Converter v1.0.25

Диалог завершения конвертации переведён на CustomTkinter и оформлен в цветах основного приложения. Главное окно временно затемняется на время показа модального окна результата. Путь к готовому файлу вынесен в отдельный блок. Аналогичное оформление применяется к уведомлению об остановленной конвертации; сообщения об ошибках остаются отдельными предупреждениями.
